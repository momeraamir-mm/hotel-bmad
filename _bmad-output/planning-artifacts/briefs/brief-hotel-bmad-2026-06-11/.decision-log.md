### Discovery decisions (round 1)
- **Stakes: Win this client.** It's a sales/pitch demo to land the Makkah company. Credibility + solving THEIR specific pain is paramount; operational fidelity matters more than flashy vision.
- **Hero moment: Rate comparison intelligence.** The jaw-dropper is multiple suppliers' rates for the same hotel/dates shown side-by-side, AI picking the best option + margin analysis (+ light trend insight). The brief and PRD must center on this.
- **Languages (demo): English only.** Multilingual (Arabic/Urdu/Tamil) moves to roadmap/vision, NOT built for the demo. (Mary flagged once — see below.)
- **Voice: Included.** Demo will support uploading a supplier voice note → Whisper transcription (`whisper-large-v3`) → extraction. Confirmed feasible.

### Feasibility (verified live against Groq API with provided key)
- Groq key is valid; `GET /openai/v1/models` succeeded. Demo can call Groq for real.
- Defaults chosen: chat/extraction `llama-3.3-70b-versatile`; transcription `whisper-large-v3`; optional vision `meta-llama/llama-4-scout-17b-16e-instruct`. JSON mode + tool calling available for reliable extraction.

### Open flag (Mary → momer, raised once, deferred to user)
- Client market is inherently multilingual; PDF lists Arabic/Tamil/Urdu quotations as a Phase-1 capability. Demoing English-only to WIN this client may underplay a core pain point. Low-cost middle ground proposed: build in English, render ONE Arabic sample quotation to prove the capability (Groq has Arabic-strong models). Pending user's call.

### Discovery decisions (round 2)
- **Languages REVISED → English + Arabic + Urdu.** User chose full multilingual quotation rendering (En/Ar/Ur), including RTL for Arabic/Urdu. Tamil dropped from demo scope (roadmap). Supersedes the round-1 "English only" decision.
- **Demo data: Real Makkah hotels, fabricated suppliers + rates.** Real recognizable hotel names (Swissôtel Makkah, Pullman ZamZam, Hilton Suites, Conrad, Fairmont Clock Tower, Dar Al Tawhid, Anjum, etc.) with invented supplier names, plausible SAR rates, and realistic messy WhatsApp-style supplier message text.
- **Comparison panel scope: ALL FOUR features** (user asked what this meant; Mary explained plainly and set include-all-four as default, inviting objection): (1) side-by-side table + AI best-pick with rationale, (2) configurable margin % → cost vs. client price + profit, (3) light trend/price-history insight, (4) availability + savings callout.
